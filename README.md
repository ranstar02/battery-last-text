A tiny Python program written for make.fun's
[The Battery's Last Text to Its Charger](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab)
bounty. It writes one original funny line — a phone battery's last text
message to its charger — to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output`).

## Run it

```sh
python3 main.py
```

## The line

> last request: when he asks how i died, lie. say i went out in a blaze of glory, not because you left me on 2% while he watched one more video about how to save battery life.

One line, 173 characters, plain text. The battery's dying wish isn't for
power — it's for a better obituary.
